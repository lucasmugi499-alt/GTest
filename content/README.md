# Content

Game data as YAML, loaded by the sim with YamlDotNet (from M1).

Planned files:

- `goods.yaml`
- `recipes.yaml`
- `facilities.yaml`
- `characters.yaml`
- `storylets/`
- `scenario_veyl.yaml`
- `balance.yaml`: every tunable number in the game. If a number can be tuned, it lives here, never in code.
